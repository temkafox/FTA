# ActPilot

[![Версия](https://img.shields.io/github/v/release/temkafox/FTA?label=версия&style=flat-square)](https://github.com/temkafox/FTA/releases/latest)
[![Скачиваний](https://img.shields.io/github/downloads/temkafox/FTA/total?label=скачиваний&color=2f6f3f&style=flat-square)](https://github.com/temkafox/FTA/releases)

ActPilot — оверлей поверх Path of Exile 1 для прокачки персонажа: держит перед глазами маршрут по актам, таймер прохождения, ближайшие пассивы и связки камней из вашего билда. Уровень персонажа подхватывается из игрового лога, поэтому список актуален без ручных переключений.

Это единственный нужный файл: программа запускается без установки. `Source code (zip / tar.gz)` в том же списке — исходники, скачивать их не требуется.

## Что умеет программа

* **Маршрут кампании.** Готовый список шагов по всем десяти актам PoE 1 на русском, актуальный для 3.29; шаги с очками пассивов отмечены 🕮. Пройденный шаг отмечается по `F3`, вернуться назад — `Ctrl+F3`; строка вычёркивается, полоса прогресса показывает, сколько кампании осталось.
* **Дополнительно в актах.** Под шагами каждого акта — свёрнутый список необязательного: рецепты верстака, тайники в испытаниях и прочее по желанию. На прогресс не влияет, выключается в настройках.
* **Таймер и отсечки.** Таймер стартует с первого отмеченного шага, рядом с каждым шагом остаётся его время. Отсечки можно выключить в настройках.
* **Уровень из игрового лога.** ActPilot читает `Client.txt` и сам поднимает уровень персонажа при левелапе. Путь к файлу ищется автоматически, вручную указывается в настройках. Если в игре другой персонаж, окно персонажа предложит следить за ним в текущем профиле.
* **Импорт билда из Path of Building.** В PoB нажмите Export Build и вставьте код в ActPilot — появятся вкладки «Камни и связки» и «Дерево» с тем, что нужно взять на текущем уровне.
* **План камней.** Вкладка в окне персонажа: по актам и квестам видно, какой камень брать наградой, какой купить и у кого. Значки «Q» (наградой) и «B» (купить) на камнях показывают это решение, подсказка — где и когда.
* **Мини-панель.** По `F4` рядом с оверлеем открывается маленькое окно с ближайшими пассивами, связками камней и камнями, которые нужно взять в текущем акте; клик по нему открывает полное окно персонажа.
* **Дерево пассивов и ассенданси.** Дерево показывается этапами по уровню: что уже взято и какие узлы следующие. Маршрут ассенданси считается отдельно, с привязкой к лабиринтам.
* **Ручной редактор билда.** Если PoB нет, пассивы и наборы камней по уровням можно расставить самому. Связки и камни в нём перетаскиваются мышью, связка копируется и вставляется через `Ctrl+C` и `Ctrl+V`.
* **Копирование связок.** Правый клик по связке в окне персонажа или в мини-панели копирует её состав в буфер — можно вставить в заметки или в чат.
* **Редактор шагов.** Свои акты и шаги вместо встроенного гайда — «Настройки → Редактировать шаги…». Отдельные списки для PoE 1 и PoE 2.
* **Библиотека регэкспов.** По `F6` — окно с шаблонами поиска (`.-.-.`, `b-b-b` и вашими). Нажатие копирует шаблон в буфер, изменения сохраняются сразу.
* **Несколько персонажей.** У каждого профиля свой прогресс кампании, уровень и билд; переключение не сбрасывает чужие отметки.
* **Поведение оверлея.** Окно всегда поверх игры, перетаскивается за шапку, меняет размер за угол и сворачивается в полоску. Настраиваются прозрачность, масштаб интерфейса и режим «клики сквозь оверлей».
* **Обновление из программы.** При запуске ActPilot проверяет новую версию и предлагает установить её; настройки, прогресс и билды при этом остаются (они лежат в `%APPDATA%\ActPilot`).

## Что нового в версии 1.5.1

* Новый персонаж на том же профиле больше не теряется: если в `Client.txt` левелапит не тот персонаж, к которому привязан профиль, окно персонажа пишет, кто сейчас в игре, и предлагает кнопку «Следить за … в этом профиле». Она перепривязывает профиль и сразу выставляет уровень. Раньше такие левелапы молча игнорировались.

## Как начать пользоваться

1. Скачайте `ActPilot-PoE1.exe` и положите в отдельную папку.
2. Запустите файл. Оверлей появится в углу экрана.
3. Откройте настройки (⚙), выберите игру и при необходимости укажите путь к `Client.txt` — обычно `steamapps/common/Path of Exile/logs/Client.txt`.
4. Зайдите в игру и нажимайте `F3` по мере прохождения шагов — с первого нажатия пойдёт таймер.
5. Для подсказок по билду нажмите ◆ в шапке оверлея → «Импортировать PoB» и вставьте код экспорта.

## Известные ограничения

* Сборка есть только для Windows: глобальные горячие клавиши и клики сквозь оверлей используют Windows API.
* Файл не подписан цифровой подписью, поэтому при первом запуске Windows или антивирус может показать предупреждение.
* Ссылки вида `pobb.in/...` не импортируются. В Path of Building нажмите Export Build и вставьте полный код или XML билда.
* На хоткей нельзя назначить комбинацию с `Win`, а также одиночную букву или цифру без `Ctrl` / `Alt` — иначе клавиша перестанет доходить до игры. Кнопка захвата в таком случае пишет «Недоступная клавиша».
* Уровень из лога применяется, когда имя персонажа совпадает с профилем или его класс совпадает с импортированным билдом; после этого профиль следит только за этим персонажем. Чтобы переключить профиль на другого персонажа, откройте окно персонажа и нажмите «Следить за … в этом профиле». Уровень также меняется кнопками − и +.
* Режим PoE 2 идёт без маршрута: свои шаги нужно добавить через «Редактировать шаги…». Карты лейаутов зон в сборку не входят, поэтому `F4` сообщит, что карты для шага нет.
* Кнопка «Проверить обновления» работает только в собранной версии; при запуске из исходников она об этом предупредит.
