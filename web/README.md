# ActPilot web

Мобильный интерфейс поверх того же контента, что и десктопный ActPilot: маршрут кампании по актам, уровень `−/+`, дерево пассивов из билда Path of Building.

Статика без сборки и сервера: `index.html`, `style.css`, `app.js`, `data/*.json`.

## Запуск

```bat
run_web.bat
```

или вручную:

```powershell
py -3 web/serve.py
```

Открыть http://127.0.0.1:8765. С телефона — тот же адрес с IP компьютера (порт 8765 должен быть доступен в локальной сети).

`serve.py` отдаёт файлы с `Cache-Control: no-store`: после правок достаточно обновить страницу, браузер не подставит старый `app.js`. Если кажется, что изменений нет — меню «⋯» показывает время сборки работающего `app.js`: `сборка: 10.11, 10:47 · 38 КБ`. Старое время = старая версия в кэше, нужен `Ctrl+F5`.

## Что умеет

* **Маршрут.** Тап по шагу ставит курсор прогресса: всё до него включительно становится пройденным, всё после — нет. Повторный тап по пройденному шагу откатывает прогресс к нему (шаг и всё после снимается). Пройденный шаг вычёркивается, справа остаётся отсечка, сверху — таймер и полоса прогресса. Чипы актов переключают акт, после последнего шага акт меняется сам.
* **Уровень.** Кнопки `−` и `+` (`1…100`). Уровень определяет, сколько пассивов показывать на дереве.
* **Дерево.** «Импорт PoB» → вставить код экспорта Path of Building. Зелёные ноды — взято, золотые — следующие, серые — остальное. Пинч/колесо — зум, перетаскивание — пан, тап по ноде — название и свойства.
* **Камни.** План получения камней билда по актам: `Q` — награда за квест, `B` — купить у вендора (с количеством и уровнем, с которого нужен камень). Ниже — камни, которые достаются только Divine Font, дропом или трейдом. Логика и данные те же, что в десктопном `gems/plan.py`.
* **Хранение.** Прогресс, уровень и импортированный билд лежат в `localStorage` браузера. Меню «⋯» — сброс прогресса и таймера.

## Чего нет

* `Client.txt` не читается: уровень ставится вручную (в вебе нет доступа к файловой системе).
* Ассенданси и кластерные самоцветы в полотне не рисуются; глобальных хоткеев нет.

## Обновление данных

`data/steps.json` и `data/tree.json` собраны из бандла приложения:

```powershell
py -3 tools/build_web_data.py
```

Запускать после правок `src/actpilot/steps.json` или `src/actpilot/data/poe1/skilltree.json`.
